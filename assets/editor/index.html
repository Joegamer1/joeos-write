Keyboard shortcuts

Arrows move; Shift selects; Ctrl+Left/Right moves by word. Home/End move along the line; Ctrl+Home/End move through the document.

Tab inserts a tab; Shift+Tab reduces paragraph indent. In tables, Tab/Shift+Tab move between cells; Ctrl+Tab inserts a tab.

Enter: paragraph. Shift+Enter: line break. Ctrl+Enter: page break. Ctrl+B/I/U: bold/italic/underline. Ctrl+[ or ]: change size one point.

Ctrl+L/E/R/J: left/center/right/justify. Ctrl+M or Ctrl+Shift+M: indent/outdent. Ctrl+T or Ctrl+Shift+T: hanging indent. Ctrl+1/2/5: single/double/1.5 line spacing.

Ctrl+F/H: find/replace. F3/Shift+F3: next/previous match. Ctrl+C/X/V: copy/cut/paste plain text. Ctrl+A: select all. Ctrl+Z/Y: undo/redo.

Ctrl+N/O/S: new/open/save. Ctrl+Shift+S or F12: Save As. Escape closes search.
